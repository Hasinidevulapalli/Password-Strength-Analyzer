# Password Strength Analyzer

## Description
This project evaluates the strength of a user-entered password based on:
- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

It classifies passwords as:
- Weak
- Medium
- Strong

If the password is weak or medium, the program suggests a stronger password.

## Technologies Used
- Python
- Jupyter Notebook
- re
- random
- string

## How to Run
1. Open the notebook in Jupyter Notebook.
2. Run all the cells.
3. Enter a password when prompted.
4. View the strength analysis and suggestions.
